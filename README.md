I'm Martin. I write Rust and work with AWS, mostly on DynamoDB tooling.

**[Dynoxide](https://dynoxide.dev)** - a DynamoDB-compatible engine in Rust.
A drop-in for DynamoDB Local that starts in milliseconds and runs as a native
binary, a ~5 MB Docker image, or compiled to WebAssembly in the browser.

**[Parity Suite](https://paritysuite.org)** - an independent DynamoDB
conformance benchmark. 1,054 tests run against every DynamoDB-compatible
engine and against live AWS across regions, with a published grade for how
far each one diverges. I maintain Dynoxide as well, which is stated on the
board; the same automated tests and the same open code run against every
engine.

**[Access Patterns](https://accesspatterns.dev)** - an interactive
environment for learning DynamoDB data modelling. Dynoxide compiled to
WebAssembly answers the queries, so there's no AWS account and nothing to
install.
